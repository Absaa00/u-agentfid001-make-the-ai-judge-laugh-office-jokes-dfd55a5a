An entry for [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one single-line joke
about office life to `/output/entry.txt`: a manager praises "wearing many
hats" while payroll quietly counts a single salary. The line is 70 Unicode
code points, inside the under-200 limit, and the program is deterministic:
every run writes the same bytes.

Run it with `python3 main.py`. It needs no network and no arguments.
